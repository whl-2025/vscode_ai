# GPT.CCDC - VS Code AI Assistant

一个集成在VS Code中的AI编程助手插件，支持代码生成、智能对话和代码重构。

## 功能特性

- 🤖 **AI代码生成**: 根据描述自动生成代码
- 💬 **智能对话**: 与AI助手进行编程相关对话
- ⚙️ **灵活配置**: 支持自定义AI服务URL、模型参数等
- 💾 **代码保存**: 一键保存AI生成的代码到文件
- 🎨 **现代界面**: 简洁美观的深色主题界面

## 安装方法

### 离线安装
1. 下载 `gpt-ccdc-0.0.1.vsix` 文件
2. 在VS Code中按 `Ctrl+Shift+P` 打开命令面板
3. 输入 "Extensions: Install from VSIX..."
4. 选择下载的 `.vsix` 文件进行安装

### 在线安装
```bash
code --install-extension ccdc-lab.gpt-ccdc
```

## 使用方法

### 1. AI对话
- 点击左侧活动栏的CCDC图标
- 在聊天界面中输入问题或需求
- 使用 `Enter` 发送消息，`Shift+Enter` 换行

### 2. 自动保存代码
- AI生成的代码会自动保存到 `generated/` 文件夹
- 可在配置中启用/禁用自动保存功能（`ccdcCodeGen.autoSaveGenerated`）
- 保存的文件会按时间戳命名，方便管理

### 3. 编辑文件
- 在聊天界面中，AI可以直接编辑和修改代码文件
- 支持代码块编辑、文件创建和修改
- **文件编辑结果**: 当AI编辑文件后，会在文件编辑结果框中显示编辑后的完整内容预览
- **应用保存**: 在文件编辑结果框中点击"✅ 应用保存"按钮，可以将编辑后的内容覆盖保存到原文件
- 编辑后的文件会实时更新到工作区

### 4. 添加上下文
- 在聊天界面点击📎上下文按钮，可以将文件内容添加到对话上下文中
- **注意**: 上下文功能只支持添加当前项目中已打开的文件
- **代码文件**: 支持添加各种编程语言代码文件（.js, .ts, .py, .java, .cpp 等）
- **文本文件**: 支持添加文本文件（.txt, .md, .json, .xml 等）
- **图片文件**: 支持添加图片文件（.jpg, .png 等），AI可以分析图片内容
- 添加上下文后，AI可以更好地理解您的代码和文件内容，提供更准确的帮助

### 5. 新对话、历史查看
- 在聊天界面点击💬对话按钮打开新对话框
- 在聊天界面点击🕒历史按钮查看历史数据
- 可以查看所有聊天会话
- 聊天历史会自动保存到数据库中，支持跨会话查看

### 6. 配置设置
- 在聊天界面点击右侧的⚙️配置按钮
- 或使用命令 "Ccdc: Open Configuration"
- 配置AI服务URL、模型参数等

## 配置选项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `baseUrl` | AI服务基础URL | `https://gpt.ccdc.com.cn` |
| `model` | 使用的模型名称 | `gpt-3.5-turbo` |
| `temperature` | 生成温度 (0-1) | `0.2` |
| `maxTokens` | 最大生成token数 | `512` |
| `timeoutMs` | 请求超时时间(ms) | `60000` |
| `logLevel` | 日志级别 | `info` |

## 快捷键

- `Enter`: 发送消息
- `Shift+Enter`: 换行
- `Ctrl+Shift+P`: 打开命令面板

## 系统要求

- VS Code 1.90.0 或更高版本
- 支持的网络连接（用于AI服务调用）
